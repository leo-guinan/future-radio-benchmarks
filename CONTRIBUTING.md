# Submit an experiment

Fork this repository and open a pull request adding `submissions/<your-run>/` with:

1. A completed `submission.json` using the template, track and baseline hash.
2. The recipe/config changes and environment details required to run them.
3. Artifact hashes and stable downloadable output links (large media belongs in a release).
4. All attempt receipts, including failures; measured costs, assumptions and gaps.
5. Dialogue/quality checks, independent listening findings, and any dated external outcomes.

**Track A** keeps spoken text, speaker assignment and scene order fixed. Preserve
meaningful pauses and declare timing, voice and sound-design differences. Do not
improve cost by deleting lines or accelerating dialogue. Compare comparable scopes.

**Track B** adds its own script and goal. State the outcome and measurement method
before observing the result. The reference recipe is not a generic importer: supply
an input adapter and acceptance checks for your episode. Production efficiency,
quality, audience response and participation remain separate objectives.

The challenge supplied a November 22, 2026 deadline. No independent submission is
yet claimed. Public evidence may show a disappointing result; record it honestly.
Never include credentials, account-wide usage exports or unrelated private files.
Human listening results are distinct from provider text alignment.

To compare a cached replay, report historical asset cost and incremental replay
cost separately. Zero new credits means reused synthesis, not zero original cost.
